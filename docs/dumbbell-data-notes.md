# 덤벨 비교 데이터 · 기준과 불일치 기록

데이터: `lib/dumbbells.ts` · 필터/정렬/URL: `lib/dumbbellQuery.ts` · 화면: `/dumbbells`

## 기준

- 우선 기준은 14편 조사표 「0. 종합표 · 가격순 (2026-11-12)」과 그 기준 설명.
- 가격: 한 쌍, 배송비 제외, 파워블럭 별매 거치대 제외, 그립톤 2개 구매 할인(30,000) 반영.
- 바이줌·최대 24kg 모델 제외. 써클은 2026-11-17 사용자 결정으로 제외 (방식·길이·리뷰 기록이 엇갈림).
- 평점·리뷰 수·품절은 조사 당시 기록으로만 표시.
- 원자료의 안전성 등급(최상·상·중 등)과 엑셀 「그룹 비교」 시트의 「안전성(잠정)」은 공개 화면에 쓰지 않았다. 판매자 구조 설명과 카페 후기를 문장으로 나눠 실었다.
- 구매 링크는 조사 문서에 적힌 상품번호 URL만 썼다 (추적 파라미터만 제거). 롤튼 03/04는 같은 판매 페이지.

## 2026-11-24 갱신 (볼트 「덤벨 제품 조사」 261124 추가내용)

- 가격·배송비·최소 무게 갱신: 누오벨·머슬피크·원퀵·마스터피스·그립톤·롤튼(2.25kg). 가격은 「상품 가격」(쿠폰 최대할인가 아님).
- 배송비는 `shipping` 으로 따로 표시하고 한 쌍 가격에 넣지 않는다. 한 쌍 주문 시 한 번인지 개당인지는 미확인.
- 누오벨 애쉬그레이 → 누오벨(기본 블랙), 링크 `komomall/products/5254571567`. 최소 무게 2kg.
- 프리시전 누오(품절) 삭제 → 누오 신형(올블랙, NUOBELL 232) 추가. 길이·최소 무게·확장은 미조사.
- 롤튼 이름을 「36kg (2.25kg 단위조절)」「36kg (4kg 단위조절)」로. 타입 03/04는 옵션 표기로만.
- 롤튼 4kg 단위는 낱개 169,000 (옵션 선택 시 가격, 사용자 제공 캡처). 처음에 2.25kg 단위와 같은 217,000 으로 잘못 넣었다가 정정 — 조사 문서에 같은 캡처가 들어가 있었음. 한 쌍 348,000.
- 올웨이트 오르벨(338,000 · 무료배송 · 최소 5kg)·파워블럭(한 쌍 670,000 · 배송비 23,500 · 최소 2kg)도 11-24 확인. 10개 제품 가격 전부 11-24 기준.
- **한 쌍 가격 = 낱개 × 2, 배송비는 별도 열** (사용자 기준: 낱개 구매는 없다고 가정, 배송비는 주문당 1회). 파워블럭은 세트 가격. 한때 배송비를 한 쌍 가격에 넣었다가, 대본 연출이 한 쌍 가격 기준이라 숫자가 어긋나서 11-24 에 다시 분리했다. 예산 필터·가격 정렬도 배송비 제외 한 쌍 가격 기준.
- 그립톤 2개 구매 할인(11-12 의 30,000)은 11-24 미확인이라 빼고 메모로만 남김.
- 누오벨 배송비 10,000 (사용자 제공). 누오 신형 규격: FLEXBELL i 32KG 사이즈표 — 덤벨 435 · 거치대 포함 480 · 높이 170 · 손잡이 지름 32 · 길이 105. 최소 2kg. 다이얼, 누오벨과 거의 같은 구조 (사용자). 확장도 누오벨과 같이 40kg 모델 교체 (사용자).
- 11-12 → 11-24 낱개가는 10개 제품 모두 같다 (롤튼 4kg 단위 169,000 그대로).
- 아직 11-12 값: 파워블럭 41kg 확장 키트 가격(227,000).
- 판매 링크는 상세 펼침 대신 제품 이름에 건다.
- 롤튼 링크 두 개는 네이버 쇼핑커넥트 제휴 링크(naver.me)로 교체, `affiliate: true` → rel=sponsored + 하단 수수료 안내.
- 마스터피스: 36kg 낱개 상품(`wit-fit/12176175143`, 265,000) → **32kg 판매처**(`wit-fit/13465113112`, 「32kg, 2개」 484,000 · 배송비 30,000)로 교체. 다른 제품과 같은 32kg급으로 비교하려는 사용자 결정. id `masterpiece-mark2` → `masterpiece`, 이름에서 MARK2 뺌 (32kg 페이지 사이즈표가 MARK.1).
- 마스터피스 32kg 길이 320~345mm 는 **추정**. 사이즈표가 20·36·56kg만 있고, 세 값이 1kg당 5mm씩 정확히 늘어나 비례로 계산했다.
- 마스터피스 제휴 링크 `naver.me/x0OVqyp7` 는 `channelProductNo=9054209729` 로 가서 13465113112 와 번호가 다르다. 같은 상품인지 확인 전이라 비교표엔 일반 링크를 둔다.
- 마스터피스 확장 상한 64 → **65kg** (판매 페이지 무게 옵션 최대 65kg, 사용자 캡처 11-24). 배송비는 1개마다 부과(65kg 2개 62,000).

## 원자료끼리 엇갈린 값 (섞지 않고 아래처럼 처리)

| 항목 | 엇갈린 내용 | 화면 처리 |
|---|---|---|
| 마스터피스 길이 | 0장·상세 「340~365」 ↔ 엑셀 길이 열 365 단일값(메모에 범위) ↔ 1장 본문 「360mm」 | 범위 340~365 유지. 길이 정렬·필터는 상한 365 기준, 걸치면 판단 보류 |
| 마스터피스 확장 상한 | 0장·엑셀 「64kg까지 키트」 ↔ 3장 「65kg까지」 ↔ 제품 조사 「최대 65키로」 ↔ 상세 「64kg (추가 구성 시 65·66·67kg)」 | 11-24 판매 페이지 무게 옵션 최대 65kg 로 정리 → 「65kg」. 키트 가격은 조사표에 없음 |
| 롤튼 길이 | 0장 「약 440 (판매자 답변)」 ↔ 엑셀 440 (메모에만 「약 44cm」) | 근삿값 「약 440mm」 |
| 그립톤 가격 | 1장 538,000 (할인 전) ↔ 0장 508,000 (2개 할인) | 0장 508,000 |
| 원퀵 길이 | 430 ↔ 상세 「49cm」 기준 불명 | 430 + 「49cm 기준 확인 필요」 메모 |

## 아직 확인 안 된 값

- 누오벨 최소 무게, 상세 페이지 전반 (미수집)
- 프리시전 누오 확장 방식
- 마스터피스 확장 키트 가격
- 다이얼식 제품이 무게에 따라 길이가 바뀌는지 (파워블럭만 무게별 길이 확인)
- 손잡이 치수·최소 무게 일부는 조사 단계의 추출본이며 원본 대조 전
